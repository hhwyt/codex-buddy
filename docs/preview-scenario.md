# 预览点击路线

给定时截图任务用：在 Chrome 里按顺序点一遍，在标了「📸」的地方截图。界面改了，这份路线要跟着改。

## 准备

1. 在仓库根目录运行 `scripts/preview.sh`（只监听 127.0.0.1，端口 5180）。
2. Chrome 窗口宽至少 1000、高至少 720。预览模式会把 App 画成真实窗口大小（980×680），放在页面中间，深色背景。
3. 左下角有一条「预览模式」小条：模拟用的按钮都在这里，App 里没有它。
4. 想看别的窗口大小，在网址后面加 `size=宽x高`，比如 <http://127.0.0.1:5180/?size=1090x570>（1366×768 笔记本开 125% 缩放时窗口大约这么大）。

所有按钮都按**按钮上的文字**找。模拟后端的时间是固定的，下面写的「等 N 秒」照做就能截到对应画面。

## A. 安装四屏

打开 <http://127.0.0.1:5180/>

1. 📸 **欢迎屏**：左边三个绿色对勾小标签「免费」「不用科学上网」「不花一分钱」，大标题「一键装好 Codex / 免费用 AI」，渐变大按钮「开始」（外圈有一圈轻轻扩散的光），按钮下面一行「① 点开始 — ② 微信扫码 — ③ 自动装好」。右边是秒表样式的圆形计时器：一圈 60 个刻度，中间「从零到能用 / 0.0 / 秒」，下面一行小字「点「开始」后开始计时」。
2. 点「开始」，等 1 秒。
3. 📸 **欢迎屏·计时开始**：按钮变成「已开始」，计时器跳了一下、外圈有两道波纹往外扩，数字在走（如 `1.2`），刻度一格一格亮起，下面一行变成转圈加「正在检测电脑…」。
4. 再等 2 秒。
5. 📸 **扫码屏**：标题「用微信扫码，免费用 AI」，三条编号提示；下面两个小标签：绿色对勾「检测电脑：Windows 11 专业版 · x64」，转圈「正在后台下载 Codex N%」；右边渐变边框里是二维码（预览里是假的）。右上角黑色计时胶囊「● 已用时 N.N 秒」，红点在闪，每过一整秒数字轻轻跳一下。
6. 点左下角「（预览）模拟扫码成功」，等 2 秒。
7. 📸 **自动进行屏**：标题「搭子正在帮你装，不用管它」，右边「3 / 5」，下面一条渐变进度条。五行：检测电脑、安装 Codex、获取免费 Key、配置模型、测试连通。做完的行是绿色圆圈加白色对勾，右边绿色用时（如「0.9 秒」）；正在做的行在转圈、向右微移、有一道光扫过，「安装 Codex」那行下面有一条下载进度条；没轮到的行是灰色数字圈，写着「等一下就轮到它」。
8. 等 8 秒。
9. 📸 **完成屏（视频封面）**：顶部绿色小胶囊「✓ Codex 已装好」，「从零到能用」，渐变超大数字「NN 秒」（先从 0 数上去，到数后弹一下），两边撒彩纸（约 5 秒后停），四周有几颗闪烁的小星星。数字下面三个小胶囊「扫码 1 次」「自动完成 5 步」「花费 0 元」，再下面「用的是智谱免费模型 glm-4.5-flash」，大按钮「打开 Codex」，链接「以后想换模型、换语言，点这里」，最下面「关注黄金金不AI，看入门教程」。右上角计时胶囊变成绿色「共用时 N.N 秒」。彩纸停了以后再截一张，适合当封面。
10. 点「打开 Codex」：底部提示「预览模式：在 App 里这里会打开 Codex」。
11. 点「以后想换模型、换语言，点这里」，进入管理页（接着走 B）。

## B. 管理页

也可以直接打开 <http://127.0.0.1:5180/?state=installed>（跳过安装，直接进管理页）。

1. 📸 **管理页·切换模型**：左上绿点加「Codex 已装好，可以直接用」，大字「正在用：智谱免费」，下面一行「模型 glm-4.5-flash · 汉化版 · Codex …」；右上「打开 Codex」。四个标签带小图标：切换模型、中文 / 英文、常用设置、还原。一行绿色盾牌小字「每次切换：先自动备份，再测试连通，测通了才保存。没测通就什么都不改。」三张卡片：智谱免费（排第一，彩色边框，右上「免费」，标题旁绿色「正在用」，按钮变成浅绿色「✓ 正在用」）、智谱付费（带「模型」下拉框）、OpenAI 官方账号。下面一张宽卡片「其他厂商」：地址、Key、模型名和「测试并保存」在一行。「推荐厂商」位置第一版是空的，不显示。
2. 在「智谱付费」卡片的「模型」里选「GLM-4.6」，点这张卡片的「用这个」，等 1 秒。
3. 📸 **切换弹窗·测试中**：标题「切换到：智谱付费」。上面三个大圆点连成一条线：① 备份（绿色对勾）— ② 测试连通（在转圈）— ③ 保存（灰色）；下面逐行打勾：备份现在的配置、准备新配置、测试连通：让 glm-4.6 回一句话。
4. 再等 3 秒。
5. 📸 **切换弹窗·成功**：三个圆点全是绿色对勾，连线变绿；底部绿色框「切换好了，正在用：智谱付费」「Codex 开着的话，关掉重新打开一次就生效。」，按钮「好的」。点「好的」：顶部变成「正在用：智谱付费」（文字从下往上弹出），「智谱付费」卡片闪一圈绿光。
6. 点「OpenAI 官方账号」卡片的「登录并使用」，等 6 秒：弹窗里多一行「在弹出的浏览器里登录你的 OpenAI（ChatGPT）账号」，最后绿色框「切换好了，正在用：OpenAI 官方账号」。点「好的」。
7. 在「其他厂商」卡片里填：地址 `https://api.example.com/v1`，Key `bad-test-key`，模型名 `demo-model`，点「测试并保存」，等 4 秒。
8. 📸 **切换失败**：三个圆点：① 备份是绿色对勾，② 测试连通是红色叉（抖一下），③ 保存是灰色。「测试连通」那一行红底红字「Key 不对，或者没有权限用这个模型」。底部红色框「没切换成功，原来的配置没动」，下面写原因。按钮「复制日志」「好的」。点「复制日志」，底部提示「日志已复制…」。点「好的」。
9. 把 Key 改成 `good-test-key`，再点「测试并保存」，等 4 秒，绿色框「切换好了，正在用：其他厂商」，点「好的」，顶部变成「正在用：其他厂商」。
10. 点「智谱免费」卡片的「用这个」，等 4 秒，点「好的」，回到「正在用：智谱免费」。
11. 点标签「中文 / 英文」。📸 两张大卡片，每张上面画了一个小窗口：汉化版（菜单「文件 编辑 查看 帮助」，渐变色，标题旁白色「✓ 正在用」）、英文原版（菜单「File Edit View Help」）。点「英文原版」，等 2 秒，绿色框「切换好了，现在是英文原版」，点「好的」，顶部那行变成「英文原版」。再点「汉化版」切回来，点「好的」。
12. 点「常用设置」。📸 两行：「AI 改文件前要不要问我」（要问 / 不用问）、「思考深度」（快 / 平衡 / 深），下面一行小字「改了马上保存。Codex 开着的话，重新打开后生效。」点「要问」：这一行亮一圈绿边、右边出现「✓ 已保存」，底部提示「✓ 已保存：改文件前要问」；点「深」，提示「✓ 已保存：思考深度「深」」。
13. 点「还原」。📸 左边红色圆形箭头图标，「还原到安装前的样子」，三条会做的事，一条绿色「✓ 你在 Codex 里的聊天记录不会删」，红色按钮「一键还原」。点「一键还原」，弹出确认框；先点「先不了」（什么都不发生），再点一次「一键还原」，点「确定」。
14. 📸 **还原弹窗**：还原 Codex 的配置、去掉汉化版的快捷方式、卸载 Codex 依次打勾，绿色框「还原好了」「这台电脑已经回到安装前的样子。」。点「好的」，回到欢迎屏（计时器归零、按钮又是「开始」）。

## C. 故障画面

1. 打开 <http://127.0.0.1:5180/?scenario=fix>，点「开始」，等 3 秒，点「（预览）模拟扫码成功」，等 9 秒（黄色条大约在第 8～10 秒之间出现）。
   📸 **正在帮你修**：清单下方黄色条（黄色转圈）「正在帮你修：这个版本的 Codex 不认模型菜单文件，改用默认菜单」。再等 4 秒到完成屏。
2. 打开 <http://127.0.0.1:5180/?scenario=fail>，点「开始」，等 3 秒，点「（预览）模拟扫码成功」，等 7 秒。
   📸 **修不好**：标题「遇到了一点问题」，右上计时胶囊变绿停住。清单收成一行一行（不再显示说明，没轮到的行隐藏），「安装 Codex」那一行红色叉。下面白底红框「这一步没走通」，写着原因（Windows 应用数据库坏了，0x80073CFE）和修复办法，按钮「一键复制日志」「再试一次」。点「一键复制日志」，底部提示「日志已复制，发给我们就行（里面没有你的 Key）」。

## D. 小窗口（可选）

打开 <http://127.0.0.1:5180/?size=1090x570>，按 A 走一遍；再打开 <http://127.0.0.1:5180/?state=installed&size=1090x570> 点一下「OpenAI 官方账号」的「登录并使用」。
📸 每一屏都不应有文字被截断、按钮跑出窗口；界面会自动变紧凑（标题变小、弹窗里每行只留一行字），管理页内容多时在面板里上下滚动。
