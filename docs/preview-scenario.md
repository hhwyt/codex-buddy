# 预览点击路线

给定时截图任务用：在 Chrome 里按顺序点一遍，在标了「📸」的地方截图。界面改了，这份路线要跟着改。

## 准备

1. 在仓库根目录运行 `scripts/preview.sh`（只监听 127.0.0.1，端口 5180）。
2. Chrome 窗口宽至少 1000、高至少 720。预览模式会把 App 画成真实窗口大小（980×680），放在页面中间，深灰背景。界面是 HumansLive 的设计语言（和 humanslive.ai、安装脚本同一套）：细网格、等宽小字、衬线标题、蓝色信号灯；全程只有一个强调色：蓝。
3. **两套主题，每张图截两遍**：App 像苹果那样按时间自动换，7:00–19:00 是白天（浅灰白底、白卡、深色字），其余时间是黑夜（近黑底、深色卡、浅色字）；字体、logo、布局、动画两套完全一样，到点切换时颜色约 0.5 秒渐变过去。预览里在网址后面加 `theme=day` 或 `theme=night` 固定主题。整条路线先全部加 `theme=day` 走一遍，再全部换成 `theme=night` 走一遍，同一个📸截白天、黑夜各一张，文件名后面加 `-day` / `-night`，方便并排对比。下面写的颜色，没特别说明的两套都一样（蓝色就是蓝色）；「浅色底 / 深色底」指白天 / 黑夜各自的底色。
4. 左下角有一条「预览模式」小条：模拟用的按钮都在这里，App 里没有它。
5. 想看别的窗口大小，在网址后面加 `size=宽x高`，比如 <http://127.0.0.1:5180/?theme=day&size=1090x570>（1366×768 笔记本开 125% 缩放时窗口大约这么大）。

所有按钮都按**按钮上的文字**找。模拟后端的时间是固定的，下面写的「等 N 秒」照做就能截到对应画面。

## A. 安装四屏

打开 <http://127.0.0.1:5180/?theme=day>（第二遍用 `?theme=night`）

1. 📸 **欢迎屏**：顶栏（白天浅色、黑夜深色），左边 HumansLive 的「一张脸」logo、文字「Humans | Live」和小胶囊「Codex 搭子」。背景是细网格，上面有细线慢慢流动（蓝色加少量墨色/白色，和主站首页一样）。左边：蓝色等宽小字「● HUMANSLIVE.AI ▸ CODEX」（打开时像安装脚本那样从乱码解出来），衬线大标题「一键装好 Codex，/ 免费用 AI。」（第二行蓝色），一句说明，三个描边小胶囊「✓ 免费」「✓ 不用科学上网」「✓ 不花一分钱」，蓝色按钮「开始 →」，下面一行等宽小字「01 点开始 → 02 微信扫码 → 03 自动装好」。右边一块半透明面板（白天白、黑夜深色）：顶上「TIMER　从零到能用」，中间一圈 60 个细刻度围着等宽大数字「0.0 秒」，底下「点「开始」后开始计时」。
2. 点「开始」，等 1 秒。
3. 📸 **欢迎屏·计时开始**：按钮变成描边的「已开始 →」，计时面板边框变蓝，刻度圈外有两道细蓝线往外扩，数字在走（如 `1.2`），蓝色细弧和刻度一格一格亮起，底下变成转圈加「正在检测电脑…」。
4. 再等 2 秒。
5. 📸 **扫码屏**：蓝色小字「STEP 01 ▸ 扫码登录」，衬线标题「用微信扫码，/ 免费用 AI。」，三条带 01 02 03 编号、发丝线分隔的提示；下面两行等宽小字：「✓ 检测电脑：Windows 11 专业版 · x64」「（转圈）正在后台下载 Codex N%」。右边一个外圈细蓝边慢慢明暗的框，里面是白底的登录区和二维码（两套都是白底，因为智谱登录页本身是白的）（预览里是假的）。右上角计时胶囊「● 已用时 N.N 秒」，每过一整秒数字闪一下蓝。
6. 点左下角「（预览）模拟扫码成功」，等 2 秒。
7. 📸 **自动进行屏**：蓝色小字「HUMANSLIVE.AI ▸ 正在安装」，右边「3 / 5」；衬线标题「搭子正在帮你装，不用管它」，下面一条发光的细蓝进度线。一块半透明面板里五行，左边 01–05 编号：检测电脑、安装 Codex、获取免费 Key、配置模型、测试连通。做完的行：蓝色实心圆点加白色对勾（外圈扩一下、整行闪一下浅蓝），右边蓝色用时（如「0.9 秒」）；正在做的行：左边一条蓝竖线、圆圈在转、有一道光扫过，「安装 Codex」那行下面有一条细蓝下载进度线；没轮到的行是灰字，写着「等一下就轮到它」。
8. 等 8 秒。
9. 📸 **完成屏（视频封面）**：蓝色等宽小字「● ✓ ALL SYSTEMS GO · 全部完成」（和安装脚本最后一行一样，从乱码解出来），衬线「从 零 到 能 用」，正中衬线超大数字「NN 秒」（先从 0 数上去，到数时一亮，同时一圈蓝白细线从数字后面射出去、三道细椭圆往外扩，约 2.5 秒散完），背景流线。数字下面三个描边小胶囊「扫码 1 次」「自动完成 5 步」「花费 0 元」，再下面等宽小字「用的是智谱免费模型 glm-4.5-flash」，蓝色按钮「打开 Codex →」，下划细线的链接「以后想换模型、换语言，点这里」，最下面「关注 黄金金不AI，看入门教程」。右上角计时胶囊停住，写「共用时 N.N 秒」。射线散完以后再截一张，适合当封面。
10. 点「打开 Codex」：底部提示「预览模式：在 App 里这里会打开 Codex」。
11. 点「以后想换模型、换语言，点这里」，进入管理页（接着走 B）。

## B. 管理页

也可以直接打开 <http://127.0.0.1:5180/?state=installed&theme=day>（第二遍 `theme=night`）（跳过安装，直接进管理页）。

1. 📸 **管理页·切换模型**：和安装屏同一套底色（白天浅灰白、黑夜近黑带细网格）。左上等宽小字「● MANAGE · CODEX 已装好，可以直接用」，衬线大字「正在用：智谱免费」（「智谱免费」蓝色），下面等宽小字「模型 glm-4.5-flash · 汉化版 · Codex …」；右上蓝色按钮「打开 Codex →」。四个标签在一个框里：切换模型（当前，白天墨色底白字、黑夜浅色底深字）、中文 / 英文、常用设置、还原。一行小字「● 每次切换：先自动备份，再测试连通，测通了才保存。没测通就什么都不改。」三张卡片（白天白卡、黑夜深色卡，左上 01 02 03 编号，衬线卡片标题）：智谱免费（排第一，右上描边「免费」和蓝底「正在用」，蓝色边框，按钮变成描边的「✓ 正在用」）、智谱付费（带「模型」下拉框）、OpenAI 官方账号。下面一张宽卡「04 其他厂商」：地址、Key、模型名和「测试并保存」在一行。「推荐厂商」位置第一版是空的，不显示。
2. 在「智谱付费」卡片的「模型」里选「GLM-4.6」，点这张卡片的「用这个」，等 1 秒。
3. 📸 **切换弹窗·测试中**：半透明遮罩上一张卡片（白天白卡、黑夜深色卡），顶上等宽小字「CODEX 搭子 ▸ 正在处理」，衬线标题「切换到：智谱付费」。三个圆圈连成一条细线：01 备份（蓝底白勾）— 02 测试连通（蓝色细弧在转）— 03 保存（灰色）；下面逐行打勾：备份现在的配置、准备新配置、测试连通：让 glm-4.6 回一句话（这一行浅蓝底、左边蓝竖线）。
4. 再等 3 秒。
5. 📸 **切换弹窗·成功**：三个圆圈全是蓝底白勾，连线变蓝；底部浅蓝提示条「✓ 切换好了，正在用：智谱付费」，按钮「好的」（「Codex 开着的话，关掉重新打开一次就生效。」只在 Codex 开着时出现，预览里 Codex 没开，所以不显示）。点「好的」：顶部变成「正在用：智谱付费」（文字从下往上淡入），「智谱付费」卡片外圈闪一下淡蓝。
6. 点「OpenAI 官方账号」卡片的「登录并使用」，等 6 秒：弹窗里多一行「在弹出的浏览器里登录你的 OpenAI（ChatGPT）账号」，最后浅蓝提示条「切换好了，正在用：OpenAI 官方账号」。点「好的」。
7. 在「其他厂商」卡片里填：地址 `https://api.example.com/v1`，Key `bad-test-key`，模型名 `demo-model`，点「测试并保存」，等 4 秒。
8. 📸 **切换失败**：三个圆圈：01 备份是蓝底白勾，02 测试连通是红色细圈加红叉，03 保存是灰色。「测试连通」那一行下面红字「Key 不对，或者没有权限用这个模型」。底部一个框，红字「没切换成功，原来的配置没动」，下面灰字写原因。按钮「复制日志」（描边）「好的」（蓝色）。点「复制日志」，底部浅蓝提示条「日志已复制…」。点「好的」。
9. 把 Key 改成 `good-test-key`，再点「测试并保存」，等 4 秒，浅蓝提示条「切换好了，正在用：其他厂商」，点「好的」，顶部变成「正在用：其他厂商」。
10. 点「智谱免费」卡片的「用这个」，等 4 秒，点「好的」，回到「正在用：智谱免费」。
11. 点标签「中文 / 英文」。📸 两张大卡片，和安装脚本里「选择 Codex 版本」那个窗口一样：当前的汉化版是蓝底白字（标题旁白色描边「正在用」，底下等宽小字「文件 编辑 查看 帮助」），英文原版是卡片底色加灰边（底下「File Edit View Help」）。点「英文原版」，等 2 秒，浅蓝提示条「切换好了，现在是英文原版」，点「好的」，顶部那行变成「英文原版」，英文原版那张变成蓝底。再点「汉化版」切回来，点「好的」。
12. 点「常用设置」。📸 这时正在用智谱免费，只有一张卡「AI 改文件前要不要问我」，右边框里两个选项「要问 / 不用问」（选中的蓝底白字）：智谱模型不认「思考深度」，所以这一项不显示。下面一行小字「● 改了马上保存。Codex 开着的话，重新打开后生效。」点「要问」：这张卡的边变浅蓝、右边出现蓝色等宽小字「✓ 已保存」，底部浅蓝提示条「✓ 已保存：改文件前要问」。
    （想看「思考深度」（快 / 平衡 / 深）：先切到「其他厂商」或「OpenAI 官方账号」再来这里，点「深」，提示「✓ 已保存：思考深度「深」」。）
13. 点「还原」。📸 一张卡片：等宽小字「RESTORE」，衬线标题「还原到安装前的样子」，发丝线分隔的三条「— 会做的事」，一条蓝色「✓ 你在 Codex 里的聊天记录不会删」，墨色按钮「一键还原 →」（不用红色；白天墨色底白字，黑夜浅色底深字）。点「一键还原」，弹出确认卡片（顶上「CODEX 搭子 ▸ 请确认」）；先点「先不了」（什么都不发生），再点一次「一键还原」，点「确定」。
14. 📸 **还原弹窗**：还原 Codex 的配置、去掉汉化版的快捷方式、卸载 Codex 依次打勾（蓝色），浅蓝提示条「还原好了」「这台电脑已经回到安装前的样子。」。点「好的」，回到欢迎屏（计时器归零、按钮又是「开始 →」）。

## C. 故障画面

（两个网址第二遍都换成 `theme=night`。）


1. 打开 <http://127.0.0.1:5180/?scenario=fix&theme=day>，点「开始」，等 3 秒，点「（预览）模拟扫码成功」，等 9 秒（提示条大约在第 8～10 秒之间出现）。
   📸 **正在帮你修**：清单下方一条蓝边提示条（左边蓝色信号灯）「正在帮你修：这个版本的 Codex 不认模型菜单文件，改用默认菜单」。不用黄色。再等 4 秒到完成屏。
2. 打开 <http://127.0.0.1:5180/?scenario=fail&theme=day>，点「开始」，等 3 秒，点「（预览）模拟扫码成功」，等 7 秒。
   📸 **修不好**：衬线标题「遇到了一点问题」，右上计时胶囊停住。清单收成一行一行（不再显示说明，没轮到的行隐藏），「安装 Codex」那一行是红色圆点加白叉。下面一张卡片，红色衬线标题「这一步没走通」，正文色写着原因（Windows 应用数据库坏了，0x80073CFE）和修复办法，按钮「再试一次」（描边）「一键复制日志 →」（蓝色）。点「一键复制日志」，底部浅蓝提示条「日志已复制，发给我们就行（里面没有你的 Key）」。

## D. 小窗口（可选）

打开 <http://127.0.0.1:5180/?theme=day&size=1090x570>，按 A 走一遍；再打开 <http://127.0.0.1:5180/?state=installed&theme=night&size=1090x570> 点一下「OpenAI 官方账号」的「登录并使用」。
📸 每一屏都不应有文字被截断、按钮跑出窗口；界面会自动变紧凑（标题变小、弹窗里每行只留一行字），管理页内容多时在面板里上下滚动。

## E. 到点切换（可选）

打开 <http://127.0.0.1:5180/?state=installed&theme=day>，在 Chrome 开发者工具的控制台里输入 `document.documentElement.dataset.theme='night'`，回车：整页颜色在约 0.5 秒里渐变成黑夜，不闪、布局不动；再输入 `'day'` 变回来。App 里是主程序到 7:00 / 19:00 自动做这件事。
