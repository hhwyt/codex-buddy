# 预览点击路线

给定时截图任务用：在 Chrome 里按顺序点一遍，在标了「📸」的地方截图。界面改了，这份路线要跟着改。

## 准备

1. 在仓库根目录运行 `scripts/preview.sh`（只监听 127.0.0.1，端口 5180）。
2. Chrome 窗口宽至少 1000、高至少 720。预览模式会把 App 画成真实窗口大小（980×680），放在页面中间，深灰背景。界面刻意做得很素：左上角只有「CodexBuddy」，没有 logo、背景花纹和装饰动画，每屏只放用户此刻要看、要点的东西；强调色只有蓝。
3. **两套主题，每张图截两遍**：App 按时间自动换，7:00–19:00 是白天（浅灰白底、白卡、深色字），其余时间是黑夜（近黑底、深色卡、浅色字）；布局完全一样，到点切换时颜色约 0.5 秒渐变过去。预览里在网址后面加 `theme=day` 或 `theme=night` 固定主题。整条路线先全部加 `theme=day` 走一遍，再全部换成 `theme=night` 走一遍，同一个📸截白天、黑夜各一张，文件名后面加 `-day` / `-night`。
4. 左下角有一条「预览模式」小条：模拟用的按钮都在这里，App 里没有它。
5. 想看别的窗口大小，在网址后面加 `size=宽x高`，比如 <http://127.0.0.1:5180/?theme=day&size=1090x570>（1366×768 笔记本开 125% 缩放时窗口大约这么大）。

所有按钮都按**按钮上的文字**找。模拟后端的时间是固定的，下面写的「等 N 秒」照做就能截到对应画面。

## A. 安装四屏

打开 <http://127.0.0.1:5180/?theme=day>（第二遍用 `?theme=night`）

1. 📸 **欢迎屏**：顶栏左边「CodexBuddy」。正中一个大标题「一键装好 Codex，/ 免费用 AI。」（第二行蓝色），一句「你只要用微信扫一下码，其余的自动完成。」，一个蓝色按钮「开始」（白字下的蓝比文字用的蓝深一点，黑夜也一样，保证看得清）。别的什么都没有。
2. 点「开始」，等 3 秒。
3. 📸 **扫码屏**：左边标题「用微信扫码登录」，一段说明（第一次用智谱要填手机号、收一次验证码；登录好就不用管了，后面会自动往下走）。右边一个白底框，里面是二维码（预览里是假的）。没有计时器。
4. 点左下角「（预览）模拟扫码成功」，等 2 秒。
5. 📸 **自动进行屏**：标题「正在自动安装，不用管它」，下面一张卡片五行：检测电脑、获取免费 Key、配置模型、安装 Codex、测试连通（按通常做完的先后排：Codex 在后台下载，同时建 Key、配模型）。做完的行是蓝色圆点加白勾；正在做的行圆圈在转，下面一行小字（如「下载 Codex 21%」）；没轮到的行只有灰字标题。没有编号、用时、进度条。
6. 等 8 秒。
7. 📸 **完成屏（视频封面）**：正中「装好了，从零到能用」，下面大数字「NN 秒」，一行小字「以后从桌面或开始菜单的「ChatGPT 汉化版」打开 Codex」（装的是英文原版时是「以后从开始菜单的「ChatGPT」打开 Codex」），蓝色按钮「打开 Codex」，下划线链接「以后想换模型、换语言，点这里」，最下面「关注 黄金金不AI，看入门教程」。没有背景动画。
8. 点「打开 Codex」：底部提示「预览模式：在 App 里这里会打开 Codex」。
9. 点「以后想换模型、换语言，点这里」，进入管理页（接着走 B）。

## B. 管理页

也可以直接打开 <http://127.0.0.1:5180/?state=installed&theme=day>（第二遍 `theme=night`）。

1. 📸 **管理页·切换模型**：顶上「正在用：智谱免费」（「智谱免费」蓝色），下面一行小字「模型 glm-4.5-flash · 汉化版」；右边蓝色按钮「打开 Codex」。四个标签：切换模型（当前）、中文 / 英文、常用设置、还原。三张卡片：智谱免费（排第一，蓝色边框，按钮是描边的「✓ 正在用」）、智谱付费（「模型」下拉框，按钮「用这个（按用量付费）」）、OpenAI 官方账号（「登录并使用」）。下面一张宽卡「其他厂商」：地址、Key、模型名和「测试并保存」。卡片上没有编号和小标签。
2. 在「智谱付费」卡片的「模型」里选「GLM-4.6」，点「用这个（按用量付费）」，等 1 秒。
3. 📸 **切换弹窗·测试中**：遮罩上一张卡片，标题「切换到：智谱付费」。三个圆圈连成一条线：备份（蓝底白勾）— 测试连通（蓝色细弧在转）— 保存（灰色）；下面一行灰色小字「看明细 ▸」，明细默认收起。
4. 再等 3 秒。
5. 📸 **切换弹窗·成功**：三个圆圈全是蓝底白勾，连线变蓝；浅蓝提示条「切换好了，正在用：智谱付费」，按钮「好的」（「Codex 开着的话，关掉重新打开一次就生效。」只在 Codex 开着时出现，预览里不显示）。点「看明细」能展开四行步骤。点「好的」：顶部变成「正在用：智谱付费」，这张卡片外圈闪一下淡蓝。
6. 点「OpenAI 官方账号」卡片的「登录并使用」，等 6 秒，浅蓝提示条「切换好了，正在用：OpenAI 官方账号」。点「好的」。
7. 在「其他厂商」卡片里填：地址 `https://api.example.com/v1`，Key `bad-test-key`，模型名 `demo-model`，点「测试并保存」，等 4 秒。
8. 📸 **切换失败**：备份是蓝底白勾，测试连通是红圈红叉，保存是灰色；「看明细 ▸」收起。下面一个框，红字「没切换成功，原来的配置没动」，灰字写原因。按钮「复制日志」（描边）「好的」（蓝色）。点「复制日志」，底部提示「日志已复制…」。点「好的」。
9. 把 Key 改成 `good-test-key`，再点「测试并保存」，等 4 秒，提示「切换好了，正在用：其他厂商」，点「好的」。
10. 点「智谱免费」卡片的「用这个」，等 4 秒，点「好的」，回到「正在用：智谱免费」。
11. 点标签「中文 / 英文」。📸 两张卡片：汉化版（当前，蓝底白字，标题旁「正在用」，小字「界面中文 · 从「ChatGPT 汉化版」打开」）、英文原版（小字「界面英文 · 和官方一模一样」）。点「英文原版」，等 2 秒，提示「切换好了，现在是英文原版」，点「好的」。再点「汉化版」切回来，点「好的」。
12. 点「常用设置」。📸 这时正在用智谱免费，只有一张卡「AI 改文件前要不要问我」，右边两个选项「要问 / 不用问」（选中的蓝底白字）：智谱模型不认「思考深度」，所以这一项不显示。点「要问」，底部提示「✓ 已保存：改文件前要问」。
    （想看「思考深度」（快 / 平衡 / 深）：先切到「其他厂商」或「OpenAI 官方账号」再来这里。）
13. 点「还原」。📸 一张卡片：标题「还原到安装前的样子」，三条会做的事，一条蓝色「✓ 你在 Codex 里的聊天记录不会删」，墨色按钮「一键还原」（不用红色）。点「一键还原」，弹出确认框；先点「先不了」（什么都不发生），再点一次「一键还原」，点「确定」。
14. 📸 **还原弹窗**：每一步依次打勾，浅蓝提示条「还原好了」「这台电脑已经回到安装前的样子。」。点「好的」，回到欢迎屏（按钮又是「开始」）。

## C. 故障画面

（两个网址第二遍都换成 `theme=night`。）

1. 打开 <http://127.0.0.1:5180/?scenario=fix&theme=day>，点「开始」，等 3 秒，点「（预览）模拟扫码成功」，等 9 秒（提示条大约在第 8～10 秒之间出现）。
   📸 **正在帮你修**：清单下方一条浅蓝提示条（左边一个转圈）「正在帮你修：这个版本的 Codex 不认模型菜单文件，改用默认菜单」。再等 4 秒到完成屏。
2. 打开 <http://127.0.0.1:5180/?scenario=fail&theme=day>，点「开始」，等 3 秒，点「（预览）模拟扫码成功」，等 7 秒。
   📸 **修不好**：标题「遇到了一点问题」。清单只剩已经跑过的行：检测电脑、获取免费 Key、配置模型是蓝勾（它们在 Codex 后台下载时已经真的做完了），最后一行「安装 Codex」是红色圆点加白叉（原因不在行里重复）。下面一张卡片，红字「这一步没走通」，写着原因（Windows 应用数据库坏了，0x80073CFE）和修复办法，按钮「再试一次」（描边）「复制日志」（蓝色）。点「复制日志」，底部提示「日志已复制，发给我们就行（里面没有你的 Key）」。

## D. 小窗口（可选）

打开 <http://127.0.0.1:5180/?theme=day&size=1090x570>，按 A 走一遍；再打开 <http://127.0.0.1:5180/?state=installed&theme=night&size=1090x570> 点一下「智谱付费」的「用这个（按用量付费）」。
📸 每一屏都不应有文字被截断、按钮跑出窗口；界面会自动变紧凑，管理页内容多时在面板里上下滚动。

## E. 到点切换（可选）

打开 <http://127.0.0.1:5180/?state=installed&theme=day>，在 Chrome 开发者工具的控制台里输入 `document.documentElement.dataset.theme='night'`，回车：整页颜色在约 0.5 秒里渐变成黑夜，不闪、布局不动；再输入 `'day'` 变回来。App 里是 `ui/theme.ts` 到 7:00 / 19:00 自动做这件事。
