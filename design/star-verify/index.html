装好后验证 · 5 版原型

装好 Codex 后，让 Codex 用选好的模型真的回答一句「CodexBuddy 的 GitHub 地址是什么？」，答对了算验证通过。它给的地址在 App 右侧的内置浏览器里打开（和扫码登录智谱是同一个面板），用的模型、它的回答、打开的页面，用户都看得见。

点赞分三种情况：电脑上 gh 命令行登录过，点「帮我点赞」直接用 gh 点；右侧浏览器登录过 GitHub，点「帮我点赞」在右边自动点；都没登录，按钮是「去点赞」，右边打开 GitHub 登录页，用户自己登录后自动接着点（GitHub 不登录不能点赞，实测接口返回 401）。「跳过」和「帮我点赞」一样大，跳过也算装好。每版都能点：验证中、回答、失败重试、GitHub 打不开、没登录、已点过、帮我点赞、跳过，上方可切换。仓库开源前这个功能先关着。界面和现在的 App 一样只有白天主题。

  • 第 1 版 · 步骤清单安装完成页是一张步骤清单：下载、装好、设置之后，接着两行「问 DeepSeek」「在右边打开它给的地址」，每行转圈再打勾。清单下面是点赞邀请。
  • 第 2 版 · 验证弹窗模型页上弹一个框，只盖住左边：框里依次是「用的模型」「问了什么、它答了什么」「打开了哪个页面」；右边浏览器不被遮住，页面打开的过程看得见。
  • 第 3 版 · 对话记录左边像聊天一样，一条条列出这次验证：CodexBuddy 问 DeepSeek 什么、DeepSeek 怎么答、打开了哪个页面；最后一条是 CodexBuddy 的点赞邀请，按钮就在这条消息里。
  • 第 4 版 · 卡片上验证 + 小链接不弹框，不换屏。模型卡片右上角自己转圈、打勾，卡片下面两行小字写它答了什么、打开了哪个页面；最下面一行小字「帮我点赞」和「跳过」，一样大小。
  • 第 5 版 · 打勾那一刻顺带邀请左边整屏只做一件事：中间一个大圈在转，下面三行小字依次亮起（模型、回答、页面）；页面在右边打开时圈画成对勾，写「DeepSeek 能用了」，邀请淡入。动效只在打勾这一下。
