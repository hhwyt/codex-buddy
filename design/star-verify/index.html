装好后验证

装好 Codex 后，让 Codex 用选好的模型回答「CodexBuddy 的 GitHub 地址是什么？」，答对了算验证通过；它给的地址在 App 右边的内置浏览器里打开，用的模型、回答、打开的页面都看得见。

每版都能点：验证中、回答、失败重试、GitHub 打不开、点 Star、跳过，上方可切换。仓库开源前这个功能先关着。

GitHub 已登录

已登录 GitHub：勾上「给 CodexBuddy 点个 Star」，页面打开后自动点好。

  • 第 2 版 · 验证弹窗
  • 第 3 版 · 打勾那一刻

GitHub 没登录

没登录 GitHub：勾上「给 CodexBuddy 点个 Star」，右边出 GitHub 登录页，登录后自动点好。
