装好后验证 · 5 版原型

装好 Codex 后，让 Codex 用选好的模型真的回答一句「CodexBuddy 的 GitHub 地址是什么？」，答对了算验证通过，再请用户去项目页自己点 Star。

每版都能点：验证中、模型的回答、失败（原因 + 重试）、去点赞、跳过。上方可以切模型和模拟结果。点赞是请求不是门槛：「跳过」和「去点赞」一样显眼，跳过也算装好；CodexBuddy 只打开页面，不替用户点。仓库开源前这个功能先关着。界面和现在的 App 一样只有白天主题。

  • 第 1 版 · 安装抽屉里多一步验证装 Codex 的右侧抽屉里，最后多一行「用 DeepSeek 回答一句」。打勾后，在同一个抽屉里问要不要去点赞，「跳过」和「去点赞」一样大。
  • 第 2 版 · 验证弹窗装好后在模型页上弹一个框：「正在用 DeepSeek 验证」，能看到问了什么、它答了什么。答对了，框里再问要不要去点赞。
  • 第 3 版 · 在 ChatGPT 里问一句打开 ChatGPT（Codex），自动发出一句「CodexBuddy 的 GitHub 地址是什么？」，用户亲眼看到模型回答。CodexBuddy 在旁边打勾，再问要不要去点赞。
  • 第 4 版 · 卡片上验证 + 底部小链接不弹框。模型卡片右上角自己转圈、打勾，卡片下面一行小字写它答了什么；页面底部只放一个「去 GitHub 点个 Star」的小链接，旁边一个同样大小的「不再显示」。
  • 第 5 版 · 打勾那一刻顺带邀请整屏只做一件事：正在验证 → 大的对勾画出来，写「DeepSeek 能用了」，下面淡入一行邀请和两个一样大的按钮。动效只在打勾这一下。
