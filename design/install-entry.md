# 安装入口与应用图标

站主授权（2026-11-18）：「go，你接着把未安装提示条、安装抽屉和新 Logo 全部做完，Windows 上也用新 Logo，测完再交付。」

启动直接进入模型页。检测到未安装 Codex 时，模型、设置、社群页上方显示「这台电脑还没装 Codex　去安装 →」。提示条不提供关闭按钮，文字与图标垂直对齐，宽度与卡片一致。

点击提示条打开右侧安装抽屉并开始真实安装。抽屉显示安装步骤和进度；失败时保留进度，提供「再试一次」「复制日志」「进群发给我们」。复制日志前预览，Key 打码。安装成功后抽屉与提示条消失。未安装时卡片仍可选择和排序，卡片上不提供安装按钮。

布局以 [确认的可点击原型](http://127.0.0.1:8765/codex-buddy-team/install-prompt-protos/v4b.html) 为准。图标源文件为 [build/icon.svg](/Users/hwy/dev/codex-buddy/build/icon.svg)，应用侧栏、窗口、Windows exe、安装程序、卸载程序及 Mac 应用均使用该图标的对应格式。
