## 1. 整体结构

```
第一次打开 ──► 引导（没有左栏）：欢迎「开始安装」→ 自动安装 Codex ──► 模型页
以后打开 ───────────────────────────────────────────────────────► 模型页

装好后的窗口：
┌────────┬──────────────────────────────┬──────────────┐
│ 模型    │                              │              │
│ 设置    │       当前页面                │  右侧浏览器   │
│ 帮助    │                              │ （可开可关）  │
│         │                              │              │
└────────┴──────────────────────────────┴──────────────┘
        右上角：🛡 安全　🌐 浏览器开关
```

- **左栏**：模型、设置、社群 / 帮助（站主 2026-11-10；不要分隔线）。「学习」这一版隐藏（站主：「先隐藏掉吧，以后再加」）；下一期的「分身」插在「模型」下面。
- **不要主页**：站主问了三次「主页是干嘛的」，说明名字和内容对不上。状态那一行放在模型页最上面，打开 App 直接进模型页。
- **右上角两个图标**：🌐 浏览器开关（站主：浏览器不放导航栏，右上角一个开关就行），🛡 安全面板（见 §6）。
- **窗口像原生 App，没有标题栏那一道**（站主 2026-11-10，学 ChatGPT 的 Mac App）：隐藏系统标题栏，红绿灯嵌在左栏顶上，窗口里不写 CodexBuddy；Windows 自绘一体化顶部，最小化 / 最大化 / 关闭叠在右上角。这也顺带解决了「名字出现两遍」（问题清单 #1）。Electron 里对应 Mac `titleBarStyle: 'hiddenInset'`、Windows `titleBarOverlay`。
- **视觉：Codex 原样**（站主 2026-11-12：「我们就用风格一吧」，整套替换之前的蓝色加渐变；样张见 [codex-looks.html 第 1 个](http://127.0.0.1:8765/codex-buddy-team/ui-design/codex-looks.html)）。色值取自本机 Codex App：底色 `#fff`，侧栏和标题区 `#f9f9f9`，线条 `#ededed`；文字三层 `#0d0d0d` / `#5d5d5d` / `#8f8f8f`。主按钮 `#0d0d0d` 底、白字、胶囊形；次按钮白底、`#ededed` 边框。蓝 `#0285ff` 只用在「正在用 / ✓ 能用」和选中状态，要底色时用 `#e5f3ff`；绿 `#00a240` 只表示成功，红 `#e02e2a` 只表示出错。左栏选中项：黑色 6% 透明度底、字 `#0d0d0d`，没有蓝条。系统字体，字距 -0.01em，圆角 8–14px。不用渐变、扫光、发光、呼吸动画（转圈、进度这类表示状态的动效保留）。厂商图标用官网真实图标，正式 App 打包进安装包，不在运行时去官网拉。模型卡形状：现在是钱包叠卡（站主 11-11 采纳）；评审在出银行卡造型 5 版，站主挑完再改。各页面样子以 [screens.html](screens.html) 为准，用户走一遍见 [journey.html](journey.html)。

## 3. 各页面

### 3.1 引导（第一次打开，没有左栏）

1. **欢迎**：产品定位是「Codex 从安装到使用全生命周期的免费助手，用国产大模型」（站主 2026-11-10）。标题「Codex 免费助手 / 国产大模型」，按钮「开始安装」，别的都不放（站主：「字数要尽量简洁」「页面一定要简洁」）。各屏文案以 [journey.html](journey.html) 为准。
2. **自动安装**：检测电脑 → 安装 Codex（下载、装进「应用程序」）。已经有 Codex 时这一行直接打勾，写「已装好」。
   安装中遇到能自己修的小问题（比如这个版本的 Codex 不认模型菜单文件）自动修，出一行「正在帮你修：…」，修好接着走。
3. 装好直接进模型页，**没有完成屏**。
4. 失败：故障屏，一句原因加下一步，主按钮「再试一次」（从失败的那一步接着做），次按钮「复制日志」，紧跟「进群发给我们」（去社群页）。
5. 已经有 Codex 而且配过模型（比如站主的 M3 用的是官方账号）：**跳过引导**，直接进模型页，顶上显示它现在用的那个。

### 3.2 模型（打开 App 默认进这里）

**顶上一行状态**，回答「现在能不能用」：

| 情况 | 显示 | 按钮 |
|---|---|---|
| 刚装好，还没选 | ✓ Codex 装好了，选一个模型就能用 | 无（「打开 Codex」先不显示） |
| 正常 | 正在用：智谱免费 ✓ 能用 · 模型 glm-4.5-flash | 打开 Codex |
| 免费模型被限速 | 智谱免费暂时被限速，等一会儿就恢复 | 换个模型 |
| 付费模型没额度 | DeepSeek 余额用完了 | 去充值 |
| 连不上或配置坏了 | ✗ Codex 现在用不了 | 一键修复（重跑安装那几步，做过的跳过） |
| Codex 被删了 | ✗ 没找到 Codex | 重新安装 |

打开模型页时在后台测一次连通（约 1–2 秒，测的时候转圈）。

**卡片**：DeepSeek、智谱、OpenAI 官方账号、＋其他厂商（站主 2026-11-10：DeepSeek 第一、智谱第二）。**智谱只有一张卡片**（站主：一个 Key 不该分免费、付费两张）：同一个账号、同一个 Key，卡片上不放开关（站主 2026-11-12 去掉；模型在 Codex 自己的菜单里选，见 approved-spec「模型菜单只列当前这一家」）——免费＝glm-4.5-flash，永远不扣钱；增强＝GLM-4.6 等，按量从余额扣，选增强时出现「¥」去充值。切到增强也走测试连通，余额不够就打开充值页（「推荐厂商」位置第一版不显示）。正在用的那张抽到叠卡最前面，蓝色边框；露在后面的写「✓ 正在用」。有 Key 的卡片右上角有「⋯」→「换 Key」；付费卡片上有「去充值」。

**点「用这个」**（一键配好，不叫「安装模型」：模型在厂商服务器上，电脑上不用装东西）：
1. 要登录的（智谱、DeepSeek）右侧浏览器自动打开官方登录页，用户扫码；智谱免费和增强是同一个账号、同一个 Key，扫一次码就行，来回切不用再扫。
2. App 自动建 Key → 测试连通 → 保存。弹窗里三步「备份 → 测试连通 → 保存」，每步明细收在「看明细」里；下面一行小字「这一步只连了 open.bigmodel.cn」。
3. 结果：
   - **智谱免费**：直接能用，**不跳充值页、不提充值**。只说一句「用得多被限速了，可以换成付费的」。
   - **付费模型，测得通**（有赠送额度或有余额）：「能用了，账户里还有额度，可以先试试，用完再充」，按钮「先用着」；右侧浏览器顺便打开充值页放着。
   - **付费模型，余额不够**：「账户余额不够，充值后就能用」，右侧浏览器打开充值页；充完点「再试一次」。不去查余额数字，只看测试连通的结果。
   - **其他失败**：「没切换成功，原来的配置没动」加一句原因，「复制日志」「好的」。
4. **第一次选好模型成功**：弹窗写「装好了，从零到能用 N 秒」（N 从点「开始安装」算起），「打开 Codex」，关注行「关注 黄金金不AI，看入门教程」。这是视频封面那一刻。
5. Codex 开着时切换成功：多一句「Codex 开着的话，关掉重新打开一次就生效」。不替用户关 Codex。

**OpenAI 官方账号**：登录走系统浏览器，不走右侧浏览器（用 Google 账号登录时，Google 会拦住嵌在 App 里的浏览器）。

**换 Key**（站主 2026-11-10：自动换，不用用户粘贴 Key）：卡片「⋯」→「换 Key」→ 右侧浏览器打开官方登录页，用户扫码，App 自动建新 Key → 测试连通 → 通过才替换，不通保持原来的。没有「粘贴 Key」。「其他厂商」本来就是用户自己填的，不在此列。

### 3.4 设置

一页三块（站主 2026-11-10 去掉了「改文件前问我」和「国内下载加速」两个开关）：
1. 界面：汉化版 / 英文原版（改的是 Codex 的界面语言，不是 CodexBuddy 的）。**默认英文原版**，安装时不问；选汉化版会加一个「ChatGPT 汉化版」启动器，分身跟着走（站主 2026-11-12，细节见 [approved-spec.md](approved-spec.md)）
2. 版本 1.0.0 ·「检查更新」
3. 还原：「一键还原」先弹确认框，列出会做的事：配置恢复原样、卸载这次装的 Codex（原来就有的不卸）、退出右侧浏览器里的登录；聊天记录保留。还原后回到引导。

- 国内下载加速：不给开关，一直开着（npm、pip 用国内源）。
- 改文件前问不问：不给开关，用 Codex 自己的默认（要问）；用户想改可以在 Codex 里改。

### 3.4b 更新（站主 2026-11-10：「就类似于微信一样，要弹出一个更新的提示」）

- 打开 App 时查一次新版本，开着的话每隔几小时再查一次。
- 有新版本：弹窗「发现新版本 1.1.0」+ 两三行改了什么 +「稍后」「立即更新」。点「稍后」，下次打开 App 再提醒（同一个版本一天最多弹一次）。
- 点「立即更新」：后台下载，进度环走完显示「重启」；重启后是新版本，模型、Key、设置都保留。
- 设置里一行「版本 1.0.0」+「检查更新」，手动也能查。
- 不需要写服务端程序（站主 2026-11-13：「那就用免费的 GitHub 吧」）：安装包放 GitHub Releases；版本号、模型清单、社群码、远程开关合成 `remote/config.json` 放在仓库里，App 先经 jsDelivr 读，读不到再直接读 GitHub，App 里自带一份兜底。
- 坑：Mac 上 App 自己替换自己（自动更新）要求 App 有 Apple 签名；没签名之前，「立即更新」改成在右侧浏览器打开下载页，让用户自己下新包。Windows 没签名也能自动更新，但可能弹 SmartScreen 提示。
- 不做强制更新（这一版）。

### 3.6 右侧浏览器（站主 2026-11-12 加画中画）

站主原话：「右侧还要支持画中画……除非是需要用户扫码有自动放大，或者说是用户手动点击浏览器按钮，或者浏览器要一直打开，不能关闭，除非是用户手动关闭，不论你在哪个页面切来切去都要」

浏览器有三种样子：**关着**、**画中画**（小浮窗）、**右侧面板**（放大）。

| 什么时候 | 浏览器变成 |
|---|---|
| App 自己在网页上操作（打开官方页、登录后建 Key、查余额） | 画中画：小浮窗叠在 CodexBuddy 窗口里的右下角，能拖动；角上一个小点在闪，表示 App 正在操作 |
| 要用户亲手操作（扫码、验证码、选金额付款） | 自动放大成右侧面板，窗口向右加宽约 480px（屏幕不够宽时盖住右半边）；做完缩回画中画，不自动关 |
| 用户点右上角 🌐，或点画中画 | 放大成右侧面板；面板地址栏有一个「缩小」按钮，点了缩回画中画 |
| 用户点 ✕ | 关掉。**只有这一种情况会关** |

- 在左栏的模型、设置、帮助之间切来切去，画中画和右侧面板都保持原样，不跟着页面走。
- 画中画里只能看、不能点；点一下就放大（默认，待站主确认）。
- App 启动时浏览器关着，不记住上次的状态（默认，待站主确认）。
- 真能操作的网页：用户在里面扫码、填验证码、选金额、扫码付款。CodexBuddy 自动做的只是打开到正确的页面、登录后建 Key。**不替用户点任何付款相关的按钮。**
- 地址栏只显示网址和小锁，不能输入；有后退、刷新、缩小、关闭。
- 登录状态存在 CodexBuddy 自己的数据里，和用户的 Chrome、ChatGPT 分开。
- 画中画也是安全第一层「看得到」的一部分：App 在网页上替用户做了什么，用户都看得见。

## 5. 规则

- **文案禁用词**（从 CLAUDE.md 挪来，2026-11-12）：不提、不模仿 CC Switch；不用「傻瓜」；不把「搭子」当名字用（说「自动完成」）。

**电脑上已经有 Codex**
- 正例：/Applications 里有 ChatGPT.app（bundle id com.openai.codex）→ 不下载。
- 反例：只有别的同名 App、bundle id 不对 → 当作没装。
- 拿不准：bundle id 读不出来 → 当作已装，不覆盖，日志记一笔。

**切换模型**：备份 → 测试连通 → 保存。测试连通不过就不保存，原来的配置不动。

**登录（智谱、DeepSeek）**：二维码过期由官方页面自己刷新；用户关掉右侧浏览器 = 取消，回到模型页，什么都没改；登录后建 Key 失败 → 弹窗写原因，「再试一次」重新打开登录页。

**还原**：先确认；原来就有的 Codex 不卸；还原后回到引导。

## 6. 安全（站主：「一定要消除用户的安全顾虑」「光靠在页面上说，是不行的」）

三层：用户自己看得到；App 想说谎也做不到；别人能证实。

**第一层：看得到（右上角 🛡 安全面板）**
- 你的 Key 在哪：每个 Key 一行，`sk-••••a3f9` · 存在这台电脑上 ·「在访达里显示」（Windows：在文件夹里显示）·「去官网管理」（右侧浏览器打开官方 Key 管理页，用户能看到「CodexBuddy · 创建日期」这个 Key，随时可以在官网删掉）。
- CodexBuddy 连过哪些网站：实时记录，每行是域名、厂商、做了什么、什么时候，最后一行写「没有别的了」。
- 切换弹窗底下一行小字：「这一步只连了 open.bigmodel.cn」。
- 「复制日志」先让用户看一眼要复制的内容，Key 显示成 `sk-••••`。
- 「让 AI 帮我检查」：复制一段写好的提问（带仓库地址，问 Key 会不会发到别处、连哪些网站、有没有收集数据，要求指出代码文件），提示用户粘到他自己的 AI 里（ChatGPT、DeepSeek、豆包、Codex）。
- 「查看源代码」：右侧浏览器打开 GitHub 仓库。

**第二层：做不到说谎**
- 网络白名单写死在代码里：只能连白名单上的网站，别的一律拦掉。安全面板显示的就是这份白名单本身。除了各家厂商，还有发布和远程配置用的 `github.com`、`objects.githubusercontent.com`、`cdn.jsdelivr.net`（站主 2026-11-13 改用 GitHub）。
- 不收集任何使用数据：不统计、不上报。日志只存在用户自己的电脑上。
- CodexBuddy 自己存的 Key 用系统钥匙串加密保存；写进 Codex 配置的 Key 按 Codex 自己的方式存。

**第三层：别人能证实**
- 代码开源；仓库里加 `SECURITY.md`，用大白话写 Key 怎么来、存在哪、发给谁、连哪些网站，每条标出对应的代码文件。
- 安装包由 GitHub 公开的自动流程编出来，附构建证明，谁都能核对安装包和源码对得上。没有这一条，「让 AI 检查源码」证明不了用户装的那个包。
- 签名：Mac 公证、Windows 代码签名（花钱，等站主定，见 §8）。
- 站主拍一条视频：用网络监控工具（如 LuLu）实拍，从安装到切换模型只连了那几个网站。

要老实写清楚的一点：右侧浏览器是 App 的一部分，技术上 App 能看到里面的页面，所以第二层、第三层才是真正的保证。

## 7. 测试沙盒（只在测试版）

目的：在站主的 M3 上测，碰不到已经装好的 /Applications/ChatGPT.app 和 ~/.codex。

- 测试版所有东西放在 `~/CodexBuddy-Test/`：Codex 配置、CodexBuddy 自己的数据、右侧浏览器的登录、装的 Codex。
- 装的 Codex 叫 **Test-ChatGPT.app**（站主 2026-11-10 定），放在 `~/CodexBuddy-Test/Applications/`，用自己的 bundle id 和数据目录，关掉自动更新，能和原来的 ChatGPT 同时开。
- 测完删掉 `~/CodexBuddy-Test/` 就回到原样。正式版没有这个开关。

## 8. 平台、状态、发布、待定

**状态寿命**
- 落盘：当前模型、汉化版 / 英文原版、改文件前要不要问、备份（还原用）、右侧浏览器的登录、上次取到的课程列表和社群码。
- 断网：正在做的那一步失败，「再试一次」从失败的那一步接着做。
- App 中途被关、电脑重启：已经装好就进模型页；没装好就从欢迎屏开始，已经下载的不重下，已经建好的 Key 不重复建。

**发布**
- Mac：Apple Silicon，macOS 版本跟 Codex 的要求走。给普通用户发需要 Apple 签名和公证（每年 99 美元），**等站主定**；不定的话 Mac 这一版只给站主测。
- Windows：沿用现有安装包，hwy-pc 开机后在真机上走同一份定稿。

**开发前要实测（不通就隐藏对应功能）**
1. DeepSeek 只有 Chat Completions，Codex 要 Responses：能不能直接接上。
2. DeepSeek 登录后能不能自动建 Key；新账号没余额时报什么错。（要站主的 DeepSeek 账号，可能要充一点钱，测前先问站主）
3. Mac 上 Codex 安装包的官方下载地址，能不能静默装进沙盒。
4. 智谱、DeepSeek 有没有推广返利计划（给「去充值」用，不影响这一版）。

**站主还没定的**
- 卖课平台用哪家（默认小鹅通），等有课再定。
- Mac 签名公证花不花钱。
- 企业微信开通后换掉社群占位码。

**可以发布的标准**：在全新环境（Mac 用测试沙盒）从「开始安装」走到第一次选好模型，再走一遍换模型、换 Key、去充值、汉化版 / 英文原版、还原，每一步和线框一致；测试前后 ~/.codex 和 /Applications/ChatGPT.app 没有任何变化；用网络监控工具确认只连了白名单上的网站。
