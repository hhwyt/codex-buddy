## 验收行

每行在真实 App（Mac 测试版，测试沙盒里）按同一条路径走一遍，截图和线框对照，通过了打勾。

### 安装

- [ ] A1 [欢迎](wireframes/index.html#welcome)：页面里没有「CodexBuddy」顶栏（只在系统标题栏里出现一次）；标题「一键装好 Codex / 免费用 AI」，不带标点；只有一个主按钮「开始」。
- [ ] A2 [扫码登录](wireframes/index.html#login)：右边是智谱真实的登录页（不是假二维码）。扫码登录后自动进入「安装中」；点「返回」回到欢迎屏，什么都没改。
- [ ] A3 [安装中](wireframes/index.html#progress)：五行依次是检测电脑、获取免费 Key、配置模型、安装 Codex、测试连通；做完一行打一个勾，不用点任何东西。
- [ ] A4 已经装了 Codex（打开原型开关「电脑上已经有 Codex」）：「安装 Codex」那一行直接打勾，写「已装好」，不下载，不改 App 本身。
- [ ] A5 小问题自动修：出现虚线提示「正在帮你修：…」，修好后自动往下走。
- [ ] A6 [故障屏](wireframes/index.html#failed)：只列出已经跑过的行，失败的那行是 ✗；一句原因加下一步；主按钮「再试一次」，次按钮「复制日志」。点「再试一次」从失败的那一步接着做，已经完成的不重做。
- [ ] A7 [完成](wireframes/index.html#done)：「装好了，从零到能用」、用了多少秒、「用的是智谱免费模型 glm-4.5-flash」、主按钮「打开 Codex」、链接「以后想换模型、换语言，点这里」、关注行。
- [ ] A8 「打开 Codex」打开的是装好、配好的 Codex（测试版里是 Test-ChatGPT）。

### 管理页

- [ ] B1 [切换模型](wireframes/index.html#manage:model)：顶上「正在用：X」和「模型 … · 汉化版 / 英文原版」，右边「打开 Codex」。卡片顺序：智谱免费、智谱付费、DeepSeek、OpenAI 官方账号、其他厂商。正在用的那张描粗边，按钮是「✓ 正在用」。
- [ ] B2 任意一张卡片切换：弹窗三步「备份 → 测试连通 → 保存」，成功后「切换好了，正在用：X」→「好的」，顶上随之改变。
- [ ] B3 切换失败（其他厂商 Key 不对）：「测试连通」是 ✗，「没切换成功，原来的配置没动」加一句原因，按钮「复制日志」「好的」。原来的配置确实没变。
- [ ] B4 DeepSeek「登录并使用（按用量付费）」：先弹 DeepSeek 官方登录页，登录后自动建 Key 并走 B2；关掉登录页回到管理页，什么都没改。
- [ ] B5 DeepSeek 余额不够：失败原因写「DeepSeek 账户余额不够，充值后再试」，按钮「去充值」「好的」。
- [ ] B6 「去充值」（智谱付费、DeepSeek 卡片上）：用系统默认浏览器打开对应的官方充值页，App 不再做别的。
- [ ] B7 Codex 正开着时切换成功：多一句「Codex 开着的话，关掉重新打开一次就生效。」；Codex 没开时不出现。
- [ ] B8 [汉化版 / 英文原版](wireframes/index.html#manage:edition)：点另一张卡片就切过去，弹「切换好了，现在是 X」。打开 Codex 后界面语言确实对。
- [ ] B9 [常用设置](wireframes/index.html#manage:settings)：「要问 / 不用问」点了就存，底部提示已保存；重开 App 后还是这个选项。
- [ ] B10 [还原](wireframes/index.html#manage:restore)：「一键还原」先弹确认框，「先不了」什么都不发生；「确定还原」后逐项打勾，「还原好了」→「好的」回到欢迎屏。原来就有的 Codex 不卸载。
