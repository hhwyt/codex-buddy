## 4. 验收方式

1. **代码测试**：上面每个编号都有测试，测试名带编号；覆盖率 ≥ 85%，`core` ≥ 95%（[build-plan 第 2 版](../../codex-buddy-team/product/build-plan-2026-11-13.md) §4）。
2. **真机亲手点**（站主 2026-11-12：「一定要让 agent 亲自去操作，去用 computer use 去点击使用每一个功能」）：代理在 **Mac mini** 和 **Windows 真机**上，用 computer use 逐个功能实际点击、使用，覆盖上面每个编号。7 家厂商逐家切换、逐家做分身；每一家都打开 Codex 的模型菜单逐个核对（M-24 至 M-26、C-06），确认都能用。不符合预期的就修，修完再测。
3. 7 家的登录都在 CodexBuddy 自己的右侧浏览器里做，站主一次登录完。
